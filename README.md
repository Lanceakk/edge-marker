## 本地预览

直接双击打开 `index.html` 即可查看（推荐）。

或使用开发服务器（需要 Node.js）：

```bash
npm install
npm run start   # 使用 Vite 启动开发服务器
```

构建（可选）：

```bash
npm run build   # 输出到 dist/ （已忽略进 git）
```

## 部署

本项目为纯静态站点，已配置好部署到 GitHub Pages：

1. 推送到 GitHub 仓库后
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选 `main`，Folder 选 `/`（根目录）
5. 保存后，几分钟即可通过 `https://<用户名>.github.io/<仓库名>/` 访问
